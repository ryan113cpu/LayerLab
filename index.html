Before you get started

A few things you might be wondering.

3D printing has a couple of quirks. Here are the basics before you send an idea over.

Do I need a finished 3D model?

No. You can start with a sketch, a photo for reference, dimensions, or just a description of what you want the object to do. Whether design help is possible depends on the project.

What kind of file should I send?

If you already have a model, STL and 3MF are common 3D-printing formats. STEP files can also be useful for some design workflows. Mention what you have in the project message rather than sending a file you aren't sure about.

Can every design be 3D printed?

Not always as-is. Very thin parts, unsupported overhangs, tiny details and parts under heavy stress may need changes. The shape, size, material and printer all matter.

How much will my print cost?

There isn't one price for every print. Size, material, print time, design work and quantity all affect the cost. Use the quote form to describe the project and discuss the details.

How long does a print take?

It depends on the object's size, shape, print settings and whether a model needs work first. A realistic estimate should come after the project details are known.

Is this site a shop?

LayerLab is presented as a small maker project, not an automated store. The form starts an email conversation, and any printing, pricing or delivery arrangements need to be confirmed separately.
