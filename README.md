# LayerLab!

LayerLab is a 3D printing business website I made to show off the cool things you can create with 3D printing.

I wanted to make a homepage that looks good and shows people what my business is about. The website includes information about my 3D printing services and the kinds of things people could get printed.

I made this project using HTML and tried to make it look good while keeping it simple and easy to use.

Thanks for checking out LayerLab!
